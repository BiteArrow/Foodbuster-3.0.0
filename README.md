Foodbuster

Общий стол без хаоса — система групповых заказов для ресторанов.

Гости сканируют QR-код на столе, добавляют блюда в общую корзину, видят заказы друг друга в реальном времени. Официант и кухня получают всё одним экраном.

Установка
Шаг 1 — Установить Python-библиотеки

Нажмите Win + R, введите cmd, нажмите OK.

Вставьте команду и нажмите Enter:

python -m pip install fastapi "uvicorn[standard]" qrcode python-dotenv

Дождитесь строки Successfully installed ….

Шаг 2 — Разместить файлы

cloudflared.exe уже включён в архив — ничего скачивать дополнительно не нужно.

Первый запуск

Откройте папку с проектом в проводнике, нажмите Shift + ПКМ → «Открыть окно PowerShell здесь» (или откройте cmd и перейдите в папку).

Запустите:

python backend.py

В терминале появится:

✓ База данных инициализирована
✓ Демо-меню загружено (100 позиций)
✓ Сотрудники созданы

Откройте публичный адрес в браузере — это главная страница с QR-кодами столов.

Если туннель не запустился, откройте локальный адрес — он работает в той же сети.

Настройка туннеля (QR без Wi-Fi)

QR-коды ведут на публичный адрес — чтобы гости могли открыть их по мобильному интернету, нужен туннель.

Автоматический (рекомендуется)

cloudflared.exe в папке проекта подхватывается автоматически. Адрес отображается на главной странице и в терминале. Адрес временный — меняется при каждом перезапуске.

Для хакатона/демо: этого достаточно — запустили один раз, распечатали QR, работаете до конца мероприятия.

Постоянный адрес (Cloudflare Zero Trust)
Создайте бесплатный аккаунт на cloudflare.com
Зайдите в Zero Trust → Tunnels → Create tunnel
Скопируйте токен
Создайте файл .env рядом с backend.py:
FOODBUSTER_CLOUDFLARE_TUNNEL_TOKEN=ваш_токен_здесь

Теперь адрес будет постоянным — QR можно печатать на столешницах.

Без туннеля (только локальная сеть)
FOODBUSTER_TUNNEL=off

Гости должны быть подключены к тому же Wi-Fi.

Настройки через .env

Создайте файл .env в папке с backend.py. Пример:

ini
# Ресторан
FOODBUSTER_RESTAURANT_NAME=Моя Кофейня
FOODBUSTER_RESTAURANT_CITY=Алматы
FOODBUSTER_CURRENCY=KZT
FOODBUSTER_CURRENCY_SYMBOL=₸

# Сервер
FOODBUSTER_PORT=8097
FOODBUSTER_LOG_LEVEL=info

# Сервисный сбор
FOODBUSTER_SERVICE_PERCENT=10

# Демо-режим (отключить на продакшне)
FOODBUSTER_DEMO=false

# Туннель
FOODBUSTER_CLOUDFLARE_TUNNEL_TOKEN=ваш_токен

# Аккаунты сотрудников (заменить перед деплоем!)
FOODBUSTER_ADMIN_LOGIN=мой_логин
FOODBUSTER_ADMIN_PASSWORD=МойПароль123

Полный список настроек — в settings.py.

Роли сотрудников
Роль	Доступ
Администратор	Всё: меню, столы, сотрудники, аналитика, настройки
Официант	Карта зала, статусы столов, детали заказа, оплата
Кухня	Очередь заказов (KDS), смена статуса позиций

Сотрудники создаются и редактируются в Настройки → Сотрудники (только администратор).

FAQ

Q: Изменится ли QR после перезапуска?
A: Токены столов хранятся в базе данных — QR не меняются. Меняется публичный адрес туннеля, если нет постоянного токена Cloudflare.

Q: Как остановить сервер?
A: Нажмите Ctrl + C в окне терминала.

Q: Где хранятся данные?
A: Папка .foodbuster/ рядом с backend.py. Там база данных и загруженные фотографии.

Q: Как добавить блюдо с фото?
A: Войдите как администратор → Меню → кнопка «+» → загрузите фото (до 3 МБ, JPEG/PNG).

Q: Сколько столов поддерживается?
A: До 100 столов (настраивается через FOODBUSTER_MAX_TABLES).

Q: Работает ли на Mac/Linux?
A: Да. На Mac/Linux замените cloudflared.exe на cloudflared под свою платформу (скачать).

Q: Потеряю ли я данные при обновлении?
A: Нет, если сохранить папку .foodbuster/. База данных обновляется автоматически.
